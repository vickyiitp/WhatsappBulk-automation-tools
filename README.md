## ⚡ Core Features

- 📊 **Excel / CSV Contact Import**: Ingests recipient lists with personalized variables (`{{name}}`, `{{due_amount}}`, `{{invoice_no}}`).
- 🛡️ **Anti-Ban Intelligent Jitter**: Simulates human typing speeds and random delays between messages to prevent account bans.
- 📸 **Attachment Support**: Send customized images, PDFs, brochures, and audio voice notes automatically.
